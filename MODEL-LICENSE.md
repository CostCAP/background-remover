# Third-party model licensing

This repository contains the original Python application code and documentation. It does **not** distribute BRIA model weights.

The default model configured by the script is briaai/RMBG-2.0, downloaded by Transformers from Hugging Face when the application is run.

The current official model card identifies RMBG-2.0 as **CC BY-NC 4.0** for non-commercial use. It explicitly states that commercial use of self-hosted weights requires a separate commercial agreement with BRIA.

That license is separate from the MIT license covering the original code in this repository. The MIT license does not relicense the model weights or third-party dependencies.

Before using the model:
1. Read the current official model card and license.
2. Confirm that your intended use is permitted.
3. Obtain a separate agreement from BRIA before commercial use of self-hosted weights.
4. Do not redistribute model weights from this repository.

Official reference: https://huggingface.co/briaai/RMBG-2.0
